# Tabstr

Export all your open browser tab URLs to a text list.

## Features

- Export all tab URLs with one click
- Show tab titles (optional)
- Group tabs by window (optional)
- Copy to clipboard
- Download as `.txt` file
- Preferences are remembered

## Installation

### Chrome / Brave / Edge

1. Download or clone this repository
2. Go to `chrome://extensions/` (or `brave://extensions/` / `edge://extensions/`)
3. Enable "Developer mode" (top right toggle)
4. Click "Load unpacked"
5. Select the `tabstr` folder

## Usage

1. Click the Tabstr icon in your browser toolbar
2. Toggle options:
   - **Show tab titles** - Display page titles above URLs
   - **Group by window** - Organize tabs under window headers
3. Click **Copy to Clipboard** or **Download .txt**
